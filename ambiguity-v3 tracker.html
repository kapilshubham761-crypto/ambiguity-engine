[Mem] memory.py

Temporal Memory Layers

Three timescales: working (fast), episodic (4h), semantic (7d).

  • reinforce() → always working; promote to episodic → semantic
  • value() = weighted sum across all three layers
  • Decay: 0.97^min / 0.9997^min / 0.99997^min
  • Atomic write to data/memory.json

[Ep] episodes.py

Episodic Trace Graphs

Sequences not just concepts. The engine remembers trajectories.

  • Episode: {id, ts, concepts[], ambiguity, region, outcome}
  • Transition graph: A→B weight = EMA decay × 1.0 per occurrence
  • transitions_from() / cooccurrence_matrix() for abstractor
  • Rolling 1000-episode JSONL window

Step 3
[P] predictor.py

Predictive Activation Engine

Predicts what concepts should appear next. The start of anticipation.

  • predict(context) = P(next | context) from transition graph
  • pre_activate() pushes top-K into working memory (gain=0.08)
  • System pre-activates concepts before retrieval occurs
  • No training needed — purely from experienced sequences
Complete
Step 4
[X] contradiction.py

Contradiction Engine

Incompatible models coexist. Contradiction is a cognitive driver.

  • Detection: hot(A) ∧ hot(B) ∧ bidirectional transitions A↔B
  • Contradictions stay alive until explicitly resolved
  • Feeds GoalEngine "resolve_contradiction" drive
  • Persists: {concept_a, concept_b, conflict_type, tension_a/b}
Complete
Step 5
[Sim] simulator.py

Internal Simulation Space

Hypothetical cognition without committing state. Imagination begins.

  • simulate(context, steps) → trajectory dict (pure functional)
  • Copies working memory → scratchpad, runs Predictor propagation
  • Returns {steps[], terminal_concepts, total_concepts_touched}
  • Zero side effects — safe to call any time
Complete
Step 6
[Rf] reflection.py

Self-Reflection Layer

Structural self-observation. The system models its own cognition.

  • report() → {mode, entropy, ambiguity_load, novelty_balance, goal}
  • Pathology flags: over_fixating / drifting / looping / stuck
  • describe() → one-line natural language cognitive summary
  • Reads all subsystems — purely non-invasive
Complete
Step 7
[Ab] abstractor.py

Concept Abstractor

Higher-order concepts emerge automatically from co-occurrence clusters.

  • Reads cooccurrence_matrix() from EpisodeStore
  • Union-find cluster detection on weighted co-occurrence graph
  • AbstractConcept: name="~"+central, emergence_score, stability
  • stability = fraction of members in semantic memory layer
Complete
Step 8
[Go] goals.py

Goal Formation Engine

Emergent directional behavior. Not hardcoded tasks — intrinsic drives.

  • 5 drives: reduce_uncertainty, increase_novelty, resolve_contradiction,
    maintain_stability, expand_regions
  • goal = argmax(weight × signal_strength)
  • Updates every 10 background ticks — lightweight
  • Goal feeds ReflectionMonitor + future homework bias
